# Image_to_pdf_converter
A Python Tkinter-based desktop application that converts multiple images into a single PDF document with automatic image scaling and page formatting.

Image to PDF Converter is a desktop application developed using Python and Tkinter that allows users to convert multiple image files into a single PDF document. The application provides a simple graphical user interface where users can select images, preview the selected file names, specify an output PDF name, and generate a PDF with properly scaled and centered images.

## Features

* Select multiple image files at once.
* Supports JPG, JPEG, PNG, BMP, and GIF formats.
* Displays selected image names in a list box.
* Allows users to specify a custom PDF file name.
* Automatically resizes and centers images to fit PDF pages.
* Generates a multi-page PDF with one image per page.
* User-friendly graphical interface built with Tkinter.

## Technologies Used

* Python
* Tkinter (GUI Development)
* Pillow (Image Processing)
* ReportLab (PDF Generation)
* OS Module (File Handling)

## Working

1. Users select one or more image files.
2. Selected file names are displayed in the application.
3. Users enter a desired PDF name.
4. The application processes each image, scales it proportionally, and places it on a PDF page.
5. A final PDF document containing all selected images is generated and saved.

## Applications

* Creating PDF reports from images.
* Combining scanned documents into a single PDF.
* Organizing photographs into PDF format.
* Sharing multiple images as a single document.
